
# Project Plan: Transparent Object Dataset

## The Core Problem
Standard AI vision models fail to detect transparent medical objects (like glass tubes) because they lack visual features. Creating training data manually is too slow.

## Our Solution (The Label_Factory Pipeline)
We will use a UR Robot arm to automate the labeling process.
1. **Model:** Create simple 3D Blender models of the glass tube and box.
2. **Capture:** The robot takes multi-angle photos of the real objects while tracking its exact camera coordinates.
3. **Align:** We manually match the 3D Blender model to the real object in a single frame.
4. **Automate:** The software uses the robot's movement data to automatically project the 3D model onto the real object in all remaining frames, instantly generating pixel-perfect labels.

## Publication Goal
* Publish the transparent object dataset open-source.
* Evaluate existing AI models on this new dataset and summarize the performance in a research paper.
