# Project operating notes

- Work from the project root. The measured Windows environment uses Python 3.12.9, Blender 4.3.2, Ultralytics 8.4.127, PyTorch 2.5.1+cu121, torchvision 0.20.1+cu121, OpenCV, NumPy, and PyYAML. The local CUDA device 0 is the NVIDIA GeForce RTX 4050 Laptop GPU. Pinned ML dependencies are in requirements.txt; install the CUDA wheels as documented in README.md.
- The STL-generated dataset uses classes `0: Tube_Holder`, `1: Glass_Tube`, `2: Slide_Holder`, `3: Eppendorf_Rack`. Legacy datasets elsewhere in the repository have different mappings.
- `python scripts/yolo_dataset_splitter.py --dataset dataset --check` audits the frozen 800/100/100 split, image/label hashes, decoded-pixel uniqueness, and distinct split paths. Without a mode flag it performs a dry run; `--apply` creates/completes a split without deleting image/label data. It intentionally validates exactly 1,000 nonempty-label, 640-square images.
- Portable `dataset/data.yaml` omits `path`; scripts pass its absolute filename so Ultralytics resolves the root from the YAML location. Do not substitute a working-directory-dependent `path: .`.
- The Blender generator loads the four unchanged STL filenames from stl_models/. It refuses output directories containing a split_manifest.json. Use a fresh `--out-dir dataset_reproduced` for new renders, then split that directory before training. Never bypass this guard to regenerate the published holdout.
- `python -m py_compile blender/generate_synthetic_dataset.py scripts/yolo_dataset_splitter.py scripts/train_yolo.py scripts/evaluate_yolo.py scripts/prepare_publication.py` is the narrow syntax check. Legacy scripts/test_yolo.py is an older inference utility, not a unit test suite.
- `python -u scripts/train_yolo.py --dataset dataset --weights yolov8n-obb.pt --epochs 30 --imgsz 640 --batch 16 --device 0 --name stl_synthetic_800_30ep_reproduction` starts fresh training from the original DOTA-pretrained checkpoint. It validates best.pt and predicts all 100 test images with ten fixed-seed previews. It is expensive, not a preview-viewing command; do not launch duplicate jobs. Do not initialize this experiment from a labware checkpoint trained on all 1,000 images.
- `python scripts/evaluate_yolo.py --weights weights/best.pt --dataset dataset --split test --device 0 --output runs/obb/new_test_evaluation` evaluates without training. Output must be a new directory. It saves frozen metric JSON, curves and annotated batches; do not rerun model evaluation merely to reformat already-saved results.
- Current published assets are dataset/, stl_models/, weights/{best,last}.pt, and results/baseline/{training,validation,test}/. Ten published preview PNGs are in results/baseline/test/previews/. Other new runs, caches, original input copies and generated root preview directories remain ignored.
- The user explicitly chose to KEEP legacy tracked files unchanged. Do not untrack or move historical datasets, model folders, editor files or other legacy artifacts without new authorization. Do not stage unrelated dirty .blend files, YOLO_Dataset files or Label_Factory changes.
- `python scripts/prepare_publication.py` audits the publication. `--copy-assets` is a maintainer operation requiring the original stl_synthetic_800_30ep_holdout run and Data Sets/STL dataset inputs; it copies into the public layout, verifies SHA256, preserves originals and refuses differing existing targets. The publication manifest records the copied asset hashes; the dataset manifest records image/label hashes.
- Preserve .gitattributes `-text` rules for dataset/ and results/: newline conversion would invalidate frozen byte-level hashes. Historical absolute paths in result JSON/YAML are provenance, not portable runtime configuration. After staging a publication, `python scripts/prepare_publication.py --verify-index` checks the actual Git-index asset bytes against frozen SHA256 values, verifies required files are present, and rejects unrelated staged changes or legacy deletions without modifying the index.
- Validation chooses checkpoints; test data must not choose training hyperparameters. Report only the matching frozen checkpoint's scores. These are synthetic holdout results, not real-camera accuracy or robot grasp success. The saved standalone confusion matrices use confidence 0.001; the ten preview images use 0.25.
